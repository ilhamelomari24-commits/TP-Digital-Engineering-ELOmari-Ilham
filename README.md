## 📋 Bilan des Commandes Git Utilisées

### 1. `git status`
* **Rôle :** Permet d'afficher l'état actuel de l'espace de travail et de la zone d'index (fichiers modifiés, non suivis, ou prêts à être validés).
* **Bilan dans le projet :** Utilisé pour s'assurer que le répertoire de travail est propre (*working tree clean*) avant de changer de branche ou de publier les modifications.

### 2. `git remote -v`
* **Rôle :** Permet de lister les dépôts distants enregistrés ainsi que leurs URL pour les opérations de lecture (`fetch`) et d'écriture (`push`).
* **Bilan dans le projet :** Utilisé pour vérifier que le dépôt local pointe bien vers l'URL du projet distant sur GitHub (`origin`).

### 3. `git log --oneline --graph --all`
* **Rôle :** Permet d'afficher l'historique de tous les commits sous forme de graphe textuel condensé (une ligne par commit), incluant l'ensemble des branches.
* **Bilan dans le projet :** Indispensable pour visualiser le cheminement des branches, la création de la branche de fonctionnalité (`feature/message`), et la validation du commit de fusion (`92bd5d9`) après la résolution du conflit.
